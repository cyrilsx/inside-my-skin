# Architecture Decision Records

One file per decision, named `ADR-NNNN-<slug>.md` (NNNN zero-padded, starting at 0001).

Each ADR contains: context, decision, consequences (positive and negative), and status.

ADRs are locked once accepted: a task never reopens one. If a task appears to require
violating an ADR, the agent is blocked and must report the conflict instead of improvising.
